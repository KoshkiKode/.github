# KoshkiKode — Organization Defaults

This is the [KoshkiKode](https://github.com/KoshkiKode) organization's `.github` repository. It hosts the public organization profile and selected default community-health files. GitHub uses recognized defaults when a repository does not provide its own; project-specific files take precedence.

---

## Contents

| File / Folder | Purpose |
|--------------|---------|
| [`profile/README.md`](profile/README.md) | Public organization profile shown on [github.com/KoshkiKode](https://github.com/KoshkiKode) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Organization-wide contribution fallback |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Organization-wide code of conduct fallback |
| [`SECURITY.md`](SECURITY.md) | Organization-wide security fallback |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Issue forms used in this repository or as defaults where supported |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Generic pull request template; project-specific templates take precedence |

Not every file in this repository is an organization-wide default. GitHub recognizes specific root files and `.github` templates; individual projects may provide their own versions.
