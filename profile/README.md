## 👋 About KoshkiKode

KoshkiKode is an independent development studio building software and games. Our repositories span open-source projects, commercial software, and the studio's own website; check each repository for its current terms and project-specific guidance.

## Projects

| Project | What it is | Repository |
|---------|------------|------------|
| 🎮 **The Cordite Wars: Six Fronts** | Cross-platform RTS built with Godot 4.6 and C#/.NET 9. Its deterministic fixed-point simulation runs at 30 ticks per second, with LAN/local lockstep and no game backend. | [cordite](https://github.com/KoshkiKode/cordite) |
| 🧾 **Untitled Trust Builder** | Estate-planning information and document templates. It is not legal advice, and the app keeps user data on the device. | [untitled-trust-builder](https://github.com/KoshkiKode/untitled-trust-builder) |
| 🧪 **PharmaSim** | Client-side educational drug-interaction and pharmacokinetic simulator. It is not for medical use; use only fictional, non-identifying data. | [pharmasim](https://github.com/KoshkiKode/pharmasim) |
| 📚 **Unshelv'd** | Multilingual peer-to-peer book marketplace. | [unshelvd](https://github.com/KoshkiKode/unshelvd) |
| 🌿 **Vetviona** | Local-first genealogy app built with Flutter for Android, iOS, Windows, macOS, and Linux. The repository also includes an optional Node.js license/account backend and a static site. | [vetviona](https://github.com/KoshkiKode/vetviona) |
